# Karcas MK2 — Параметрический генератор металлических каркасов для ЛИРА-САПР 2024

Веб-оболочка для быстрой параметрической генерации 3D-расчетных схем одноэтажных и многоярусных производственных/складских зданий из металлоконструкций с экспортом в текстовый формат **ЛИРА-САПР 2024 (R2.3)**.

Работает локально в браузере без установки сервера и внешних зависимостей.

---

## Возможности (текущая версия v2.3.1)

* **Параметрическая 3D-топология:**
  * Настройка сетки осей по X (пролеты, шаг рам) и Y (шаг колонн).
  * Многоярусные колонны по высоте с автоматической разбивкой на конструктивные ярусы и возможностью поворота местных осей сечения на 90°.
  * Генерация стропильных ферм (треугольные и с раскосной решеткой Уоррена) с заданием высоты на опоре, в коньке и количества панелей.
  * Автоматическая расстановка вертикальных связей по колоннам, горизонтальных связей по покрытию и продольных распорок в заданных связевых блоках.
* **Интерактивный 3D-предпросмотр:**
  * Отрисовка расчетной схемы на HTML5 `<canvas>` с вращением, масштабированием и цветовой индикацией типов жесткостей и опор.
* **База сортаментов и накопительный парсер:**
  * Встроенная база стандартных профилей (двутавры ГОСТ Р 57837-2017, уголки ГОСТ 8509-93 и др.).
  * Импорт дополнительных профилей из эталонных `.txt` файлов ЛИРА-САПР с сохранением в `localStorage`.
* **Готовый экспорт в ЛИРА-САПР 2024:**
  * Формирование полного текстового файла задачи (узлы, стержни, шарниры/опоры, жесткости, привязка к `.profiles.srt` и базовое загружение собственного веса).
  * Гибридное кодирование файла (`Windows-1251` для геометрии + `UTF-8` для блока сортаментов `{13/`), исключающее потерю кириллицы при импорте в ЛИРУ.

## Быстрый старт

1. Клонируйте или скачайте репозиторий на локальный ПК.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox) двойным кликом — локальный веб-сервер не требуется.
3. Настройте геометрию каркаса, выберите сечения элементов и нажмите **«Скачать .txt для ЛИРЫ»**.
4. В **ЛИРА-САПР 2024** создайте новую задачу (признак схемы 5 — 6 степеней свободы в узле) и выполните:
   `Файл -> Импортировать задачу -> Текстовый файл (.txt)`.
